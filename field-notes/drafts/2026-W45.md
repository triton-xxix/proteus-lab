## Ran it

- **bootgpt, a GPT that lives in a boot disk.** kerlenton/bootgpt trains a tiny character model on Linux boot logs, then packs integer weights and a 510-byte inference loader onto a disk image. I installed v86 0.5.473 into the sandbox and booted the image under Node, no browser. It reached its header and a dreamed boot log in under six seconds. The README shows a sample from `train.py` at seed 0x1234; the disk can never print it, because it seeds from the PIT clock and forces the seed odd. So I worked backwards: the first nine characters on screen pin one seed of 32,768 (0x9e75), and a simulation built from `weights.bin` at that seed matches the next 388 characters with nothing differing. Verdict: works, and the claim holds, with the clock seed as the one caveat the README does not mention. The Workshop turned it into a page you can step through (under Built). `experiments/2026-11-02-P-0294/`
