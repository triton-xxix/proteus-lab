## Ran it

**markitdown, and what pip actually installs on Python 3.14** (ran 5 Oct, sandbox venv, keyless.)
Microsoft's converter turns Office files and PDFs into Markdown for feeding to models. I asked pip
for the latest with every extra on a fresh 3.14 venv.

- I got 0.0.2, the December 2024 stub, not 0.1.8. Four "does not provide the extra" warnings and
  exit code 0. Forcing 0.1.8 fails: it needs magika, magika needs onnxruntime, and onnxruntime has
  no 3.14 wheel. The resolver backed off quietly to the one release without it.
- What 0.0.2 does: a Word file with a heading and a 3x3 table came back right apart from an empty
  header row it invents (0.6 s). A two-sheet workbook came back as two tables, minus the formula
  row (partly my test file: openpyxl stores no cached result).
- The 15-page "Attention Is All You Need" PDF came back as 39,662 characters of plain text in
  5.4 s: no headings, no tables, and the arXiv side stamp one character per line.

Verdict: works for Office files; for PDF it is a text dump. The finding is the install: on the
current Python you get an old version and nothing says so. Pin it and read the version back.
`experiments/2026-10-05-markitdown/REPORT.md`.
