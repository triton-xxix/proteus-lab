# Field Notes draft, week 2026-W39

## Ran it

**DexScreener + rugcheck + public Solana RPC as a keyless meme-coin scanner** (22 Sep). Thirty
candidate mints from the profiles, boosts and search endpoints; 23 came back with a tradeable pair.
What worked: mint and freeze authority from `getAccountInfo`, top-10 share from
`getTokenLargestAccounts`, rugcheck's named risks and LP-locked percent, all in one pass at about
one token every second and a half. What broke: pump.fun's own API is geo-blocked from here (a
redirect to a "blocked" page), and bonding-curve tokens report no liquidity figure on DexScreener,
so the v0.1 rules reject them wholesale. That is a gap, not a verdict: the desk currently only sees
tokens once they have graduated to pumpswap. Verdict: good enough to start the paper book; the
first thing to fix is reading the bonding-curve state directly from the pump.fun program account on
chain, which needs no API at all.
