# Field Notes sources

Rotated weekly. Each source is checked at most once a week; each item found is checked against
`SEEN.md` before it is written up. One item a week must be installed and run in `sandbox/`.

## Fetchable without a login

| Source | How | Notes |
|---|---|---|
| YouTube | Data API v3 search (key in 1Password "Youtube API Data v3", tagged proteus) plus `yt-fetch.py` transcripts | Descriptions need the API; transcripts via youtube-transcript-api |
| GitHub trending | `https://github.com/trending` via browser pane, `gh api` for repo details | Filter: pushed in the last 30 days, README present |
| Awesome lists | awesome-claude-code, awesome-mcp-servers, awesome-agents | Diff against last week's copy |
| Claude skills and plugins | SearchSkills, SearchPlugins tools; skills marketplace pages | Note what is new and what is popular |
| Hacker News | `https://hn.algolia.com/api/v1/search?tags=story&query=` | Free API |
| Product Hunt | browser pane, daily leaderboard | AI category |
| arXiv cs.AI, cs.CL | `http://export.arxiv.org/api/query?search_query=` | Titles and abstracts; read one paper a fortnight properly |
| r/ClaudeAI, r/LocalLLaMA, r/solana | browser pane only; fetch is blocked on all routes | Read, never post |
| DexScreener, pump.fun | public APIs | Grinder's own sources double as field notes |
| LeaseLoco, Leasing.com | browser pane | Car lease deal radar slot |

## Not fetchable

Instagram (login wall, caption only via the embed endpoint) and TikTok. Covered only when Luke
sends a screenshot. Recorded once, not re-tried.

## Weekly slots

1. Ran it: one tool, repo or skill installed and executed in `sandbox/`, 200-word note, verdict.
2. Watched it: up to five videos, transcripts pulled, claims checked, one line each.
3. Read it: repos, papers, threads. One line each, novelty first.
4. Wildcard: one item with no link to any venture or interest of Luke's.
5. Luke-adjacent curiosity: cars, fixtures, whatever he mentioned in passing.
6. If you feel like it: the one-line asks for Luke's hands, if any.
