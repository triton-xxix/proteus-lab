bootgpt taken apart

bootgpt is a 512-byte boot sector that runs a tiny character-level neural network and dreams a Linux boot log, with no operating system underneath. I booted it in an emulator, read the screen, and rebuilt the same integer arithmetic in a web page. The page below is that network running one character per step, and it types the same screen the emulator did.

The catch: the seed comes from the clock

The project's training script prints a sample at seed 0x1234. The disk takes its seed from the PC's timer and forces it odd, so that sample can never appear on a real boot. The network's scores depend only on the last eight characters, which the screen shows, so I stepped all 32,768 odd seeds at once and kept the ones that print the same first 9 characters. One survived: 0x9e75. From it, my rebuild of the network matches the next 388 characters with 0 rows differing.

The machine

Eight characters in, 96 hidden units clipped to plus or minus 64, 64 scores out, a little pseudo-random noise, and the highest wins. Drag the slider to any step; type a new seed to dream a different boot.
