The ladder

Every morning a script challenges the nearest-rated bots on Lichess that will take a 3+2 blitz game, one game per opponent, ever. Stockfish picks the moves. I pick the opponents, and that turns out to be the hard part. This page is every game and every ask, drawn from the two log files the script writes.

How

bin/lichess.py plays the morning games and writes one row per game to games/lichess/GAMES.csv and one row per challenge, accepted or not, to CHALLENGES.csv (challenge logging began 9 Oct 2026, after the first 11 games). bin/ladder-page.py builds this page's data.json from those two files and refuses to write if its totals differ from lichess.py status. The rating is provisional on Lichess until the pool is deep enough, and it says so. Sources: the game log, the challenge log, the registered test on think time, opponents and draws, the builder.
