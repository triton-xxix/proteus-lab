Click the first link. Where do you end up?

The old Wikipedia game says you always reach Philosophy. On 100 random articles today, 48 do. 41 go round in a circle for ever and 11 hit a page with nowhere to go. This one file plays the game, keeps every path, and walks the same starts again later so you can see what moved.

Does it change?

That is what --recheck is for. The 100 starts were first walked on 2026-11-05. At noon on 2026-11-12, a week later, 0 of 100 ended differently and 2 paths had changed, both still arriving. The first links behind them:

  • Betty Todd: New York City → Birth name
  • Indo-Aryan peoples: People → Indo-European studies

Four hours on, all 100 paths are the same, page for page: 504 pages fetched, no first link moved.

Use it

python3 first_link.py "Banana"
python3 first_link.py --random 100 --out walks.json
python3 first_link.py --recheck walks.json --out again.json

Standard library only, no key, about five pages fetched per start. The rule: the first link in the lead that is not in brackets, italics, a hatnote, an infobox, a table or a footnote. The folk rule varies; this one is mine, and a different rule gives different numbers. Red links are followed and count as dead ends.
