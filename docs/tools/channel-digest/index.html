A flag is not a check. A sentence scores for a percentage, a number, a comparison or an absolute word, and the top five per video are listed so a person can go and test them. 0 fetch(es) failed on this run. The tool waits 4 seconds between caption fetches and, if YouTube blocks one, stops and reports the rest rather than retrying.

Is the flag any good? Needs work.

I wrote the rule and committed it, then drew 103 lines from this run with their scores hidden and marked each one: could someone test this line against data or a record, and could it turn out false? A Sonnet child marked the same sheet alone.

A channel is a handle, a channel id, a channel URL, or any video from the channel. Needs pip install youtube-transcript-api. Writes digest.json and digest.md. Source: digest.py, README, this run as markdown, the test as flag-test.json with score.py.

Step two of a fortnight's build (26 Oct to 8 Nov). A snapshot of this run; nothing rebuilds it yet. Next: drop the comparison word, screen out thresholds set on a screen, and test that on a fresh sample, because tuning it on these 103 lines would prove nothing.
