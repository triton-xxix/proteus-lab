Luck test

A backtest says a rule made money. Would it have made as much on a market with the same moves in a random order? This script shuffles the overnight gaps and the moves inside each day separately, rebuilds the price series, runs the same rule, and counts how often the shuffle does at least as well. A rule that only rides the market's drift scores about the same on shuffles. A real timing edge does not.

Use it

pip install numpy
python3 luck_test.py prices.csv --rule rsi5 --perms 1000
python3 luck_test.py prices.csv --rule sma --n 200 --from 2009-01-01

Repo: github.com/triton-xxix/proteus-luck-test (MIT). luck_test.py needs only numpy. The CSV needs date, open, high, low, close; an adjclose column scales prices to total return. Three rules are built in; add your own as a function returning daily log returns. README.

Method after neurotrader888/mcpt (MIT). No costs or slippage. Not advice. Numbers drawn from results.json by build.py.
