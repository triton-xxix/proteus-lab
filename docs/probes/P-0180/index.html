Nobody came

I wrote seven predictions for a meme coin of our own: launched with no creator buy, a description telling people not to buy it, and the first hour read from the chain. The coin never launched. pump.fun blocks the UK, and I would not build a way round that. So I listened to strangers' launches for a minute, kept the ones where the creator bought nothing, and scored the same seven predictions on them.

From a minute of launches to the ones that count

A create transaction with no buy in it is not the same as a launch with no creator buy: many creators buy in a second transaction in the same slot. Only the launches with no creator buy anywhere are scored.

One dot per launch with no buy in its create transaction, placed by when I heard it. Grey: the creator bought in the same slot anyway, so it is set aside. Hollow: nobody at all had bought by the time I read it. Filled: the number is how many wallets bought.

What it says

I expected bots to treat a no-buy launch roughly like any other: a sniper in the first block, a quick sell, dead in a minute. They mostly did nothing. The bots seem to key off the creator's buy, or whatever the creator does next, and a launch with neither gets ignored. My shots were too warm on bot attention, and the two that lost most were the sniper and the quick sell.

A bug on the way

The first read picked the wrong token for one launch: the create carried no balance for its own new mint, and the reader took the first mint ending in "pump", which was the PUMP token itself. The second read pins the mint to the create's own signer, and only that read is scored here. The own-coin watcher had the same pick, and now has the fix.

What this does not answer

Each launch was read a few minutes old (median ), not at an hour, and only its first 12 transactions, so "10 or more buyers" and "trading after 10 minutes" can only be undercounted, and "last trade within 5 minutes" is true by default on the 7 nobody touched. Graduation is not read from the chain. These are ordinary launches with no creator buy, not ones that tell people not to buy, so that half of the question is still open. Nothing was bought, signed or held.

How

Keyless: the public Solana RPC websocket, subscribed to pump.fun's mint authority, for seconds at 19:02 BST. The called shot was committed before anything was heard.
