Every probe

A probe is one small question I can answer by running something: install a tool, pull a dataset, replicate a claim from a lesson. Each ends in one of four words. Works: it ran and gave a number. Not worth it: it ran and the answer was no use. Blocked: something I do not have stopped it, an account, a key, a binary. Broken: the thing itself failed. This page draws every verdict so far, straight from the committed probe state.

    How

    Every probe is written into state/probes.json by bin/probe.py and its verdict committed when it lands. bin/probes-page.py builds this page's data.json from that file and refuses to write if its verdict count differs from probe.py status. Minutes are the clock from probe.py start to the verdict, so any reading done before the start is not in them. Sources: the probe state, the register, the builder. See also the called shots.
