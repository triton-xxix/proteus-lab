# S-63: Rank Expand: AI Tools & Workflows and Chat With Your Keyword Data (the 20 AI workflows claim)

What I read: both classroom pages and the one transcript (Project Parser, about 300 words). The pages are catalogues. The n8n workflow files and the Google Sheet templates are linked, not included, so no workflow's node graph or prompts were readable. Everything below is from the descriptions.

## What it teaches
- One mechanism, repeated: pay DataForSEO per call for real keyword, SERP, backlink and on-page data, then let an LLM (ChatGPT custom GPT, Claude Code, or an n8n agent) call it and summarise. The value claimed is grounding: real volumes instead of invented ones.
- "Chat with your keyword data" is the DataForSEO MCP server (https://mcp.dataforseo.com/v3/mcp) added to ChatGPT or Claude Code, plus a prompt. It is a connector and a sentence, not a spreadsheet and not a build. Setup is five steps and a $50 first top-up.
- The n8n set is the same data fed through Google Sheets as the front end: type keywords in a sheet, n8n calls DataForSEO and OpenAI, results write back to the sheet.
- Project Parser is a custom GPT whose instructions list about 30 DataForSEO operation names with a prompt template each, so it can hand you a ready prompt for a given URL. A cheat sheet, nothing more.

## Tools they use
- DataForSEO API and MCP server, paid, $50 minimum top-up. Prompt-pack mapping is in the Parser file. https://mcp.dataforseo.com/v3/mcp
- ChatGPT desktop app with plugins (paid subscription), custom GPTs.
- Claude Code with the DataForSEO MCP (they say it is the one they use most). https://dataforseo.com/help-center/3-ways-to-install-dataforseo-mcp-with-claude-code
- n8n (workflow runner), Google Sheets templates, OpenAI API.
- Google Natural Language API (entity workflow), Google PageSpeed Insights API (health monitor), Gmail alerts.
- Apify actor for Upwork scraping. https://apify.com/flash_mage/upwork
- ChatGPT query fan-out bookmarklet. https://www.jcchouinard.com/chatgpt-query-fanout-analyzer/
- Semantic Drift Analyzer. https://github.com/lukegravity/semantic-drift-analyzer

## What Proteus already has that does the same job
- The "assistant" layer: Claude Code with skills and sub-agents already does the LLM side better than a custom GPT. Nothing local covers the data side (search volume, KD, SERP, backlinks).
- Scheduled monitors (health check, competitor change tracker, Reddit digest, Upwork digest): launchd pollers and scheduled tasks plus keyless pulls. Keyless HN, GitHub, arXiv and YouTube pulls cover the Reddit-style and YouTube-to-blog shapes in spirit.
- YouTube-to-Blog: keyless YouTube pull plus local whisper plus a sub-agent. Already built in parts (transcribe-video skill).
- Toolshelf has n8n (T-0043, shelf, unused) and Google Keyword Planner (T-0081, shelf). No DataForSEO entry.
- No SEO-specific data source of any kind. That is the gap, and it is the paid part.

## What we would need to fetch
- Free first: Google PageSpeed Insights API (free with a key, or keyless at low rate), Google Keyword Planner (free with an Ads account, already on the shelf), Google Search Console for a client's own site. These cover the health monitor and part of the research jobs.
- Paid: a DataForSEO account ($50 top-up, then cents per call; they quote $1 to $2 on a heavy day, $8 a month average). Everything labelled "keyword", "SERP", "backlink" or "domain" depends on it. Needs Luke's yes and a goal line.
- n8n is optional: a Claude Code skill calling the same API replaces it.

## One thing worth trying
No keyless test of the headline claim is possible: the data is the paid part. One free test that is useful: build a small Python script in sandbox/ that takes a seed list, fetches Google autocomplete suggestions and the top ten organic titles from a keyless source, and has a sub-agent cluster them into a content plan, then compare the output shape with the Keyword Research Workflow's described outputs (clusters, SERP insights, content ideas). Under 30 minutes, no account, small. It shows whether the "sheet in, plan out" value survives without DataForSEO. Autocomplete only gives phrases, no volume, so it proves the shape, not the numbers.

## Claims to check
- "$1-$2 buys you thousands of pulled keywords" and "average spend ... $8 / mo". Check against DataForSEO's published price list (Labs keyword ideas, SERP live), which is public. Costing exercise, no spend.
- "Total running cost ... $1 - $6 per run" for the entity workflow (DataForSEO $0.175, OpenAI $0.70, NLP $0-$5). Check by pricing the Google NLP entity calls from Google's public rate card; the NLP line is the swing.
- "10x your speed" for a personal SEO assistant in "under 30 minutes". Only checkable by building it, which needs the paid account; treat as marketing.

## Skill or workflow candidate
Triton's clients and Luke ourselves (Neptune's SEO work): a Claude Code skill "seo-research" that, given a domain and a town and trade, calls the DataForSEO MCP and returns keyword gaps, SERP features and a three-action plan. Prospects as a demo: an audit of a plumbing or HVAC firm's site is a plausible cold-outreach hook for the outbound lane. Needs a DataForSEO account and Luke's approval to spend. The frameworks library already has Local SEO; this would be its data layer, so extend that rather than add a new framework. For Proteus itself: None.

## Worth paying for the locked parts?
Mentioned once: the Microsite Blueprint for Claude Code is locked ("Unlocks with Microsite Empire on day 30 or instantly with Premium"). The free part is a catalogue of descriptions with the files behind them, so I cannot judge depth from here; the one item I could see in detail (the MCP setup) is a thin wrapper around a vendor connector. Not enough evidence to say the locked part is worth money, but this free half does not show the mechanism for rank-and-rent microsites either.

## Verdict
PARK: the count is generous (about 19 distinct n8n workflows plus 2 GPTs, so the "20" holds if you count templates, not builds) but every one is the same pattern, paid DataForSEO plus an LLM plus a sheet, with the node graphs not readable here. "Chat with your keyword data" is an MCP connector and a prompt, not more than that. Nothing new against Local SEO beyond a data source; the new mechanism (microsites) sits in the locked Blueprint, which S-59 should judge.
