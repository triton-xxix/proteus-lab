# S-06: Agent J 7-Day Challenge (Start Here, Days 1-2; drip-fed) beside the AIS one

## What it teaches
- Agent J (Days 1-2 only, written, no video): an automation is trigger, steps, result. Pick work that repeats, has writable rules and has a start signal. Avoid anything needing live judgement.
- Day 2: an MCP is a connector that lets the AI act on a tool or read data. List each tool the job touches as read or act. Connect the least access needed.
- The "skill" on offer is a fill-in-the-brackets prompt template (job, five rules, one example output) pasted into a chat. It is a saved prompt, not a SKILL.md with front matter.
- AIS (for contrast) teaches a real build each day: WAT (markdown workflow, agent, scripts), Firecrawl MCP, real skills with progressive loading, Trigger.dev deployment, scheduled tasks and loops, a status file, an executive assistant project.
- Teaching versus packaging: Agent J is concept-first and gentle, with a "just in time" keys approach and an upsell to paid paths. AIS is build-first with more mechanism, and its stack pitch is Trigger.dev, Vercel and Firecrawl.
